# Documentation Guide

This document explains the purpose of every Markdown file in the project. These files form the complete Game Design Document (GDD) for Project Elysium and act as the single source of truth throughout development.

---

# 00-Overview.md

A high-level summary of the project, including what Project Elysium is, its goals, target audience, and overall direction.

---

# 01-Vision.md

Defines the long-term vision of the game, the experience players should have, and the design philosophy that guides all future decisions.

---

# 02-Core-Pillars.md

Lists the fundamental principles that every feature should support, such as exploration, progression, player freedom, social interaction, and immersion.

---

# 03-Roadmap.md

Outlines the planned development phases, milestones, and major releases from pre-production to launch.

---

# 04-Version-History.md

Tracks completed versions, update summaries, and significant gameplay changes throughout development.

---

# 05-Future-Plans.md

Contains long-term ideas, planned expansions, and features that are intended for future updates.

---
