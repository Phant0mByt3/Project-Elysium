# 0302 — Skills

## Overview
Skills are the active and passive abilities a class uses in combat, unlocked progressively while leveling ([0305-Leveling.md](0305-Leveling.md)) rather than all at once.

## Skill Categories

**Core Skills** — the handful of abilities every player of a class uses regardless of specialization (e.g. a Warrior's basic weapon strikes).

**Specialization Skills** — unlocked at level 10 alongside spec choice ([0301-Specializations.md](0301-Specializations.md)), define the spec's unique playstyle.

**Utility Skills** — non-damage abilities (movement, crowd control, buffs) available to all specs of a class.

**Ultimate Skills** — a single high-impact, long-cooldown ability unlocked at max level per specialization.

## Skill Anatomy
Every skill should be documented with: name, resource cost, cooldown, range, and a one-sentence description of its mechanical and visual identity. Cooldowns and resource costs must respect the stat formulas in [0304-Stats.md](0304-Stats.md).

## Unlock Pacing
Skills should unlock roughly every 1–3 levels early on, tapering off after specialization is chosen so that talent point choices ([0303-Talent-Trees.md](0303-Talent-Trees.md)) become the primary source of build variety at higher levels — supporting Pillar 3 in [0002-Core-Pillars.md](../0000-Project/0002-Core-Pillars.md).

Full per-class skill lists are populated during Phase 2 gameplay systems development ([0003-Roadmap.md](../0000-Project/0003-Roadmap.md)).
