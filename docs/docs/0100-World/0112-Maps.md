## 1. Overview

The map system provides players with a navigable, discoverable representation of Elysium, supporting both wayfinding and the exploration-reward loop described in [0002-Core-Pillars.md](../0000-Project/0002-Core-Pillars.md), Pillar 1.

## 2. Map Types

* **World Map** — full continent overview, shows discovered regions, cities, and fast travel points.
* **Region Map** — zoomed view of the player's current region, showing quest markers, discovered landmarks, and points of interest.
* **Minimap** — always-visible HUD element showing immediate surroundings (see [1108-UI-Systems.md](../1100-Client/1108-UI-Systems.md)).

## 3. Fog of War

Regions are shown as fogged/undetailed until physically explored, revealing terrain detail as the player travels through an area. This reinforces exploration as a meaningful activity rather than a formality.

## 4. Markers

* **Quest markers** — active and available quests.
* **Landmark markers** — appear only once discovered ([0105-Landmarks.md](0105-Landmarks.md)).
* **Fast travel waypoints** — appear once visited ([0111-Fast-Travel.md](0111-Fast-Travel.md)).
* **Group member markers** — visible to party/raid members per privacy settings.

## 5. Map Art Style

Maps are hand-illustrated in a style consistent with the in-world "cartographer's guild" aesthetic rather than a generic top-down satellite-style rendering, reinforcing the handcrafted, lived-in feeling of the world (see [1300-Art-Style.md](../1300-Art/1300-Art-Style.md)).

## 6. Accessibility

Map UI supports colorblind-safe marker palettes and scalable icon sizing, per the accessibility standards in [1106-Accessibility.md](../1100-Client/1106-Accessibility.md).
