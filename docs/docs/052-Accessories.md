# 52 — Accessories

## Slot Types
* **Rings** (x2) — pure stat items, no armor class restriction.
* **Necklace** — pure stat item, occasionally carries a minor proc effect.
* **Trinkets** (x2) — the primary source of unique on-use or passive proc effects; the most build-defining accessory slot.
* **Cloak** — technically an armor slot but functions closer to an accessory in itemization variety (see [51-Armour.md](51-Armour.md)).

## Design Philosophy
Trinkets in particular should feel like discovering a build-enabling toy, not just a stat stick — a trinket that synergizes with a specific specialization's mechanic (see [41-Specializations.md](41-Specializations.md)) is preferred over a generic stat trinket whenever possible.

## Acquisition
Accessories drop from quests, dungeons, and raids like other gear ([54-Loot-Tables.md](54-Loot-Tables.md)), with select craftable rings/necklaces available through Jewelcrafting ([68-Jewelcrafting.md](68-Jewelcrafting.md)).

## Balance Considerations
Trinket proc effects are reviewed under the same cadence as class balance ([49-Balance.md](49-Balance.md)) since a strong enough trinket can distort spec balance on its own.
