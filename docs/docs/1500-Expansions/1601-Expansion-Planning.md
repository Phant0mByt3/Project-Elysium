## 1. Purpose of This Document

This document is the practical, working companion to [1501-Expansion-Planning.md](1501-Expansion-Planning.md)'s process outline — it defines the scope, objectives, and design framework applied to each individual Elysium expansion as it moves from idea to shipped content, specifying new zones, gameplay mechanics, narrative arcs, and technical requirements. It provides a structured roadmap for development, testing, and launch to ensure cohesive integration with the existing game world.

## 3. Standard Expansion Document Template

Every numbered expansion document (1500, 1600, 1700, and onward) should define:

* **Overview** — the expansion's identity in one paragraph.
* **New Content** — continent/zone, race focus, systems, dungeons/raids.
* **Narrative Hook/Role** — how it connects to prior and future story.
* **Expansion World Change** — what changes in existing areas, which zones are phased, which old areas remain accessible.
* **Status** — Unscoped, Planned, In Development, or Released.

## 4. Cross-Expansion Consistency

Later expansions must remain consistent with earlier ones — a new continent's narrative should not contradict established lore ([0200-Lore.md](../0200-Lore/0200-Lore.md)) or invalidate a prior expansion's resolution, per the "expand, don't discard" rule in [1501-Expansion-Planning.md](1501-Expansion-Planning.md).

## 5. Technical Integration Requirements

Every expansion's world content must integrate cleanly with the instance and travel systems described in [1209-Instance-System.md](../1200-Technical/1209-Instance-System.md) and [0111-Fast-Travel.md](../0100-World/0111-Fast-Travel.md) before entering full production, avoiding late-stage technical surprises.

## 6. Ownership

This framework is maintained jointly by the Creative Director, World Director, and Lead Game Designer, and is reviewed at the start of every expansion planning cycle alongside [0005-Future-Plans.md](../0000-Project/0005-Future-Plans.md).
