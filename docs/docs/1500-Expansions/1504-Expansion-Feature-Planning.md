## 1. Overview

Expansion Feature Planning lists systems, classes, professions, and activities that ship with an expansion, with priority and dependency notes.

---

## 2. Rules

- Must-have vs nice-to-have is explicit  
- Features support at least one Core Pillar  
- Engineering and art dependencies are called out early  


## 3. Feature Categories

Expansion feature planning typically spans: new zones/continents ([1503-Expansion-World-Design.md](1503-Expansion-World-Design.md)), new or expanded classes/races, new dungeons and raid tiers, new profession content, and new systemic features (a new mechanic unique to the expansion, such as Kharzul's heat/exposure layer).

## 4. Dependency Mapping

Features with cross-discipline dependencies (a new race requiring both lore work and full character art) are flagged early and sequenced so that blocking dependencies (lore approval before art production begins, for example) don't silently stall a feature late in the cycle.

## 5. Cut Criteria

When an expansion's scope must be trimmed to hit its target release window, features are cut starting with "nice-to-have" items identified in Step 1, never by silently reducing quality on "must-have" features — consistent with Pillar 5 (Quality Over Quantity) in [0002-Core-Pillars.md](../0000-Project/0002-Core-Pillars.md).
