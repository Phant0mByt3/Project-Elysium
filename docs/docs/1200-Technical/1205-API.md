# 125 — API

## Overview
Internal and (eventually) external-facing APIs supporting tools like combat logging, guild websites, and companion apps — a Phase 2+ concern, but scoped early to avoid painful retrofits.

## Internal APIs
* **Combat Logging** — structured combat event export, feeding balance analysis ([0309-Balance.md](../0300-Characters/0309-Balance.md)) and potential player-facing damage meters.
* **Economy Data** — Auction House price history ([1003-Auction-House.md](../1000-Economy/1003-Auction-House.md)) for internal economy health monitoring.
* **Guild Data** — roster, progression, and bank summaries for potential guild-management tooling.

## External-Facing (Future)
A read-only public API exposing character profiles, guild rosters, and achievement data — useful for community sites and guild-recruitment tools, similar to genre conventions. Scoped as a post-launch feature, not required for Phase 6 ([0003-Roadmap.md](../0000-Project/0003-Roadmap.md)).

## Design Principles
* All API access is authenticated and rate-limited, coordinated with [1204-Authentication.md](1204-Authentication.md) and [1206-Security.md](1206-Security.md).
* API schemas should be versioned from day one to avoid breaking third-party or internal tooling on future updates.
