# 131 — UI Style

## Overview
Visual standards for Elysium's custom UI, delivered through client mods ([111-Client-Mods.md](111-Client-Mods.md)), replacing Minecraft's default interface entirely.

## Principles
* **Diegetic Feel** — UI frames and icons should look hand-illuminated/forged rather than flat modern UI, matching the overall art style ([130-Art-Style.md](130-Art-Style.md)).
* **Faction-Reactive Theming** — subtle palette shifts (gold accents for Dawnbound, deep red/purple for Duskward) on faction-specific UI elements, per [33-Factions.md](33-Factions.md).
* **Clarity First** — health/resource bars, cooldowns, and status effect icons ([47-Status-Effects.md](47-Status-Effects.md)) must remain legible even in the busiest raid encounters.

## Key Screens
* **HUD** — action bars, health/resource, buffs/debuffs, minimap.
* **Character Sheet** — stats ([45-Stats.md](45-Stats.md)), equipped gear.
* **Talent Tree** — [43-Talent-Trees.md](43-Talent-Trees.md) visualization.
* **Auction House / Bank / Guild** panels — [103-Auction-House.md](103-Auction-House.md), [106-Banking.md](106-Banking.md), [80-Guilds.md](80-Guilds.md).

## Accessibility
UI scaling and colorblind-safe status icon design are required, not optional — see [116-Accessibility.md](116-Accessibility.md).
