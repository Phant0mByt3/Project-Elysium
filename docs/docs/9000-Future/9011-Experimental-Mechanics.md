### 3.1 Dynamic Difficulty Based on Group Skill

**Status:** *Under Consideration*

**Concept:** An opt-in dungeon difficulty modifier that adjusts subtly based on observed group performance mid-run, rather than only the fixed Normal/Heroic/Mythic tiers in [0106-Dungeons.md](../0100-World/0106-Dungeons.md).

**Notes:** Risks undermining the clear, predictable difficulty communication that [0406-Difficulty-System.md](../0400-Gameplay/0406-Difficulty-System.md) is built around; any prototype would need very transparent player-facing indicators of when and how difficulty is adjusting.

### 3.2 Weather-Reactive Combat Mechanics

**Status:** *Under Consideration*

**Concept:** Combat abilities that gain bonus effects during matching weather conditions (fire abilities empowered during an ember storm, for example), building on [0114-Weather-System.md](../0100-World/0114-Weather-System.md).

**Notes:** Charming thematic idea but risks unpredictable balance swings tied to a system (weather) not currently designed with combat balance in mind; would need weather to become more deterministic or player-visible in advance before being viable.

### 3.3 Player-Set Bounties on World Bosses

**Status:** *Under Consideration*

**Concept:** Let players contribute currency to boost a world boss's ([0108-World-Bosses.md](../0100-World/0108-World-Bosses.md)) rewards or spawn frequency, crowdsourcing engagement with under-farmed world content.

**Notes:** Interesting economic lever worth prototyping; would need careful integration with the currency sink/source balance in [1010-Currency-Sinks.md](../1000-Economy/1010-Currency-Sinks.md) to avoid becoming a pure gold-sink gimmick with no real player-driven value.
