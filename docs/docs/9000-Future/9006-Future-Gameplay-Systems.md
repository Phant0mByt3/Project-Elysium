### 3.1 Mythic+ Style Scaling Dungeon Keys

**Status:** *Under Consideration*

**Concept:** A repeatable, ever-scaling difficulty modifier system for dungeons ([0106-Dungeons.md](../0100-World/0106-Dungeons.md)), beyond the current fixed Normal/Heroic/Mythic tiers, giving endgame players an infinitely scaling challenge and leaderboard hook.

**Notes:** Would need its own dedicated reward and leaderboard track ([0808-Leaderboards.md](../0800-Multiplayer/0808-Leaderboards.md)) to avoid devaluing fixed-tier raid progression; a promising direction for a future season rather than launch.

### 3.2 Player-Run Market Stalls

**Status:** *Under Consideration*

**Concept:** Cosmetic, city-placed player vendor stalls as a more social, visible alternative/complement to the anonymous Auction House ([1003-Auction-House.md](../1000-Economy/1003-Auction-House.md)).

**Notes:** Interesting social and economy-flavor addition; would need careful scoping to avoid undermining Auction House liquidity — see [1000-Economy.md](../1000-Economy/1000-Economy.md).

### 3.3 Cross-Class Ability Borrowing

**Status:** *Under Consideration*

**Concept:** A limited system letting players temporarily borrow one ability from another class they've leveled, encouraging alt-leveling investment.

**Notes:** Would require significant class balance rework given the identity distinctiveness goals in [0300-Classes.md](../0300-Characters/0300-Classes.md); flagged as high-risk, needs a dedicated balance prototype before further consideration.
