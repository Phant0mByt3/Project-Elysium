### 3.1 Chronomancer

**Status:** *Under Consideration*

**Concept:** A time-manipulation caster class, playing with short rewinds, cooldown resets, and battlefield tempo control — distinct from the Arcanist's elemental focus.

**Notes:** High technical complexity for both server-authoritative combat replay and clear player-facing telegraphing; flagged as a strong post-launch class candidate once core six-class balance ([0300-Classes.md](../0300-Characters/0300-Classes.md)) is proven stable.

### 3.2 Beastkin-Exclusive Totemic Class

**Status:** *Under Consideration*

**Concept:** A support/utility class themed around Beastkin ancestral totem magic, tied into the Kharzul Wastes expansion's cultural focus ([1600-Expansion-02.md](../1500-Expansions/1600-Expansion-02.md)).

**Notes:** Would make sense to introduce alongside Expansion 02 rather than at launch, giving Beastkin culture a class as distinctive as their race identity in [0204-Races.md](../0200-Lore/0204-Races.md).

### 3.3 Hybrid Melee/Caster "Spellblade" Class

**Status:** *Under Consideration*

**Concept:** A class blending melee weapon combat with a smaller spell kit, occupying design space between the Vanguard and Arcanist.

**Notes:** Risks diluting existing class identity distinctiveness (Pillar consideration in [0002-Core-Pillars.md](../0000-Project/0002-Core-Pillars.md)); would need a clearly differentiated fantasy hook before being seriously pursued.
