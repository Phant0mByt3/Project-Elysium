### 3.1 Talent Tree Visual Prototype

**Status:** *Prototyped, Not Yet Committed*

**Concept:** An early interactive visual prototype of the talent tree UI ([0303-Talent-Trees.md](../0300-Characters/0303-Talent-Trees.md)) built to validate readability and navigation before full UI production begins.

**Notes:** Useful early validation exercise; findings should feed directly into [1116-Interface-Layouts.md](../1100-Client/1116-Interface-Layouts.md) once talent tree UI production formally begins in Phase 2 of the roadmap ([0003-Roadmap.md](../0000-Project/0003-Roadmap.md)).

### 3.2 Combat Feel Prototype (Vanguard vs. Arcanist)

**Status:** *Prototyped, Not Yet Committed*

**Concept:** An early gray-box combat prototype comparing the Vanguard's melee weight and the Arcanist's ranged cast rhythm, informing the combat feel standards in [0401-Combat.md](../0400-Gameplay/0401-Combat.md).

**Notes:** Directly informed the current combat design direction; retained here as a reference point for future class prototypes (see [9008-Future-Classes.md](9008-Future-Classes.md)) to follow a similar validation process.

### 3.3 Instance Load Test Harness

**Status:** *Prototyped, Not Yet Committed*

**Concept:** A synthetic load-testing tool simulating many concurrent dungeon instances to stress-test the instance server architecture ([1209-Instance-System.md](../1200-Technical/1209-Instance-System.md)) ahead of real player load.

**Notes:** A valuable internal tool worth formalizing into the standard pre-Closed-Beta testing process described in [1423-Performance-Testing.md](../1400-Development/1423-Performance-Testing.md) rather than remaining an ad-hoc prototype.
