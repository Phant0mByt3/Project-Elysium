### 3.1 Fully Player-Driven Terrain Editing

**Status:** *Set Aside*

**Concept:** Allow players to reshape overworld terrain directly, closer to a sandbox building game.

**Reason set aside:** Directly conflicts with the handcrafted, authored-world philosophy in [0002-Core-Pillars.md](../0000-Project/0002-Core-Pillars.md) and [0116-World-Generation.md](../0100-World/0116-World-Generation.md) — permanent player terrain edits would undermine the guarantee that every hill and ruin was placed with intent. Revisit only if a fully separate, opt-in sandbox mode were ever considered, which is not currently planned.

### 3.2 Full Loot Trading Restrictions (Soulbound Everything)

**Status:** *Set Aside*

**Concept:** Make all dungeon and raid loot fully soulbound with no trade window exceptions, closing off any secondary distribution.

**Reason set aside:** Testing against Pillar 4 (Cooperation) in [0002-Core-Pillars.md](../0000-Project/0002-Core-Pillars.md) showed this would undermine guild loot councils and legitimate post-kill loot correction; the current binding rules in [0514-Item-Binding.md](../0500-Items/0514-Item-Binding.md) with a limited trade window better balance anti-RMT goals against player convenience.

### 3.3 Subscription-Only Access Model

**Status:** *Set Aside*

**Concept:** Gate the entire game behind a mandatory recurring subscription rather than a one-time purchase or free-to-play-with-cosmetics model.

**Reason set aside:** Considered during early Pre-Production business model discussions but set aside in favor of keeping the monetization approach flexible and cosmetics-only per [0903-Cosmetics.md](../0900-Player-Systems/0903-Cosmetics.md); a final monetization model has not yet been formally committed and remains outside the scope of this design-focused GDD.
