# 0703 — Weekly Quests

## Overview
Weekly quests are once-per-week objectives offering larger rewards than dailies ([0702-Daily-Quests.md](0702-Daily-Quests.md)), typically tied to group content completion rather than solo objectives.

## Examples
* **"Clear the Sunken Concord"** — complete the launch raid on any difficulty for a bonus reward beyond the raid's own loot table ([0107-Raids.md](../0100-World/0107-Raids.md)).
* **"Dungeon Rotation"** — complete a rotating set of three Heroic dungeons for a reputation and Aurum bonus.
* **"World Event Champion"** — participate in a set number of world events ([0109-World-Events.md](../0100-World/0109-World-Events.md)) over the week.

## Design Rules
* Weeklies should reward participation, not just completion, where possible (e.g. partial credit for a raid clear even if the group doesn't down every boss).
* Weekly rewards should never fully replace the value of the underlying content's own loot table — they're a bonus layer, not the primary incentive.
* Reset timing should be server-wide and clearly communicated in the UI.

## Relationship to Reputation
Many weeklies feed directly into faction reputation tracks — see [0706-Reputation.md](0706-Reputation.md) and [0707-Factions-Reputation.md](0707-Factions-Reputation.md).
