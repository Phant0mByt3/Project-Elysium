## 1. Overview

Reputation tracks a character's standing with the various factions and organizations of Elysium, gating access to vendors, recipes, and quest content as it increases.

## 2. Reputation Tiers

| Tier | Typical Unlocks |
| --- | --- |
| Neutral | Base interaction, no hostility |
| Friendly | Basic vendor access |
| Honored | Discounted prices, mid-tier recipes |
| Revered | Rare recipes, cosmetic rewards |
| Exalted | Best vendor items, exclusive mounts/titles |

## 3. Reputation Sources

* Quest completion, particularly regional and daily quest hubs ([0702-Daily-Quests.md](0702-Daily-Quests.md)).
* Dungeon and raid completion for faction-aligned content.
* Turning in specific reputation tokens or items to faction representatives.

## 4. Design Rules

* Reputation gates should never block Main Quest progression — see [0708-Main-Quest.md](0708-Main-Quest.md) — only optional vendor and cosmetic content.
* Reputation grind pacing is tuned so a moderately active player reaches Exalted with a given faction within a reasonable multi-week window, not months of daily grinding.
* Reputation rewards should be desirable but not build-defining, keeping the system aspirational rather than mandatory.

## 5. Relationship to the Two-Faction System

Regional and NPC-organization reputation (Ironpeak Hold, Ashka Vor, individual guilds) is distinct from the overarching Dawnbound Concord / Duskward Pact faction alignment chosen at character creation — see [0707-Factions-Reputation.md](0707-Factions-Reputation.md) for how these layers interact.

## 6. UI Tracking

Reputation standing is tracked through a dedicated panel showing all discovered factions, current standing, and progress toward the next tier.
