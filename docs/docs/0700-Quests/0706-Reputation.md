# 76 — Reputation

## Overview
Reputation is a per-organization progress track, distinct from the two overarching player factions covered in [0707-Factions-Reputation.md](0707-Factions-Reputation.md). This document covers the general reputation system mechanics.

## Reputation Tiers
Hated → Hostile → Neutral → Friendly → Honored → Revered → Exalted — a standard escalating track, with vendor access, quest availability, and cosmetic rewards unlocking at each tier.

## Sources
* Quest completion (one-time, larger gains).
* Daily/weekly quests ([0702-Daily-Quests.md](0702-Daily-Quests.md), [0703-Weekly-Quests.md](0703-Weekly-Quests.md)).
* Dungeon/raid completion for reputation-affiliated content.
* Turning in specific reputation tokens/items to a faction's quartermaster NPC.

## Design Rules
* Reputation grinds should never be the sole gate to core power progression — cosmetic and vendor rewards are the primary payoff, with at most minor stat items gated behind higher tiers.
* Every reputation track should have a clear narrative "sponsor" NPC or organization ([0209-NPCs.md](../0200-Lore/0209-NPCs.md), [0203-Factions.md](../0200-Lore/0203-Factions.md)).
