# 77 — Factions Reputation

## Overview
This document covers reputation specifically with the two player factions, the Dawnbound Concord and the Duskward Pact ([0203-Factions.md](../0200-Lore/0203-Factions.md)), building on the general system described in [0706-Reputation.md](0706-Reputation.md).

## Faction Standing
Every character begins Friendly with their chosen faction and Neutral (capped, cannot be raised without a faction-change) with the opposing faction, reflecting the game's PvP-relevant faction divide ([0804-PvP.md](../0800-Multiplayer/0804-PvP.md), [0806-Territory-Control.md](../0800-Multiplayer/0806-Territory-Control.md)).

## Rewards by Tier
* **Honored** — access to faction-exclusive daily quest hubs ([0702-Daily-Quests.md](0702-Daily-Quests.md)).
* **Revered** — faction-exclusive mount ([0901-Mounts.md](../0900-Player-Systems/0901-Mounts.md)) and cosmetic set ([0903-Cosmetics.md](../0900-Player-Systems/0903-Cosmetics.md)).
* **Exalted** — faction-exclusive title ([0705-Titles.md](0705-Titles.md)) and a unique faction-flavored weapon transmog appearance.

## Faction Changes
A rare, costly service allowing a player to switch factions, resetting faction reputation appropriately. Not intended as a casual choice — framed narratively as a significant character decision, tying back into the main story's themes of ideological division ([0200-Lore.md](../0200-Lore/0200-Lore.md)).

## Design Rules
Faction reputation rewards should never create a raw power gap between Concord- and Pact-aligned players in PvP — cosmetic and convenience rewards only, keeping [0309-Balance.md](../0300-Characters/0309-Balance.md)'s cross-faction parity intact.
