# 112 — Resource Pack

## Overview
A comprehensive custom resource pack replacing Minecraft's default textures, models, sounds, and UI art with assets matching Elysium's original fantasy art direction ([130-Art-Style.md](130-Art-Style.md)).

## Scope
* **Block & Terrain Retexturing** — used to realize each continent's distinct biomes and architecture ([11-Continents.md](11-Continents.md), [13-Cities.md](13-Cities.md)).
* **Custom Item Models** — weapons, armor, and accessories ([50-Weapons.md](50-Weapons.md) through [52-Accessories.md](52-Accessories.md)) rendered as bespoke models rather than reskinned vanilla items where feasible.
* **Custom Mob Models** — enemy and NPC models replacing vanilla mob appearances entirely, tied to [39-NPCs.md](39-NPCs.md) and regional bestiaries.
* **Custom Sound Design** — combat, ambient, and UI sound effects supporting the combat-identity goals in [44-Combat.md](44-Combat.md).
* **Custom UI Art** — icons, frames, and menu backgrounds matching [133-Fonts.md](133-Fonts.md) and [132-Colour-Palette.md](132-Colour-Palette.md).

## Delivery
Installed and kept up to date automatically via the launcher ([110-Launcher.md](110-Launcher.md)), versioned alongside client mods ([111-Client-Mods.md](111-Client-Mods.md)).
