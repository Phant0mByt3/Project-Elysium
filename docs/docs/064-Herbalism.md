# 64 — Herbalism

## Overview
Herbalism is a gathering profession focused on collecting plants, roots, and reagents used primarily by Alchemy ([65-Alchemy.md](65-Alchemy.md)), with secondary uses in Cooking ([67-Cooking.md](67-Cooking.md)).

## Core Loop
Locate a wild herb node → gather it → use directly in Alchemy recipes or sell raw materials on the Auction House.

## Regional Distribution
Common across Aurelia's Southern Shires and Greywater Fens, with rarer alchemical herbs concentrated in more dangerous zones, incentivizing higher-level herbalists to gather in contested or high-difficulty regions rather than only low-level starting zones.

## Design Notes
Herbalism is the natural pairing profession for Alchemy, mirroring the Mining/Blacksmithing and Woodcutting/Tailoring gather-production pairs described in [60-Professions.md](60-Professions.md). Node rarity and distribution should be reviewed alongside the broader economy in [100-Economy.md](100-Economy.md) to keep potion prices stable.
