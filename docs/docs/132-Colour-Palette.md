# 132 — Colour Palette

## Overview
Defines the core color language used across UI, environment art, and effects, ensuring visual consistency per [130-Art-Style.md](130-Art-Style.md).

## Faction Colors
* **Dawnbound Concord** — gold, cream, soft blue (Solthar-associated warmth and clarity).
* **Duskward Pact** — deep red, iron grey, dark purple (Nyxara/Ignareth-associated intensity).

## Rarity Colors (Loot)
Standard escalating rarity palette per [53-Loot.md](53-Loot.md): White (Common) → Green (Uncommon) → Blue (Rare) → Purple (Epic) → Orange (Legendary) → Gold (Relic).

## Elemental Colors
Fire (orange/red), Frost (pale cyan), Nature (green), Shadow (dark violet), Holy (bright gold-white), Arcane (magenta/pink) — consistent across spell effects, status icons, and damage-type UI indicators, tied to [48-Elements.md](48-Elements.md).

## Regional Palettes
Each continent's environment art draws from a bounded palette (see [130-Art-Style.md](130-Art-Style.md)'s regional identity section) to keep zones visually distinct at a glance on the world map ([22-Maps.md](22-Maps.md)).

## Accessibility
All palette choices must pass a colorblind-safe contrast check, particularly for rarity and elemental colors that carry gameplay information — see [116-Accessibility.md](116-Accessibility.md).
