## 1. Overview

The Main Menu is the first interactive screen after the launcher hands off to the game client. It provides access to character select, settings, credits, and quit, while establishing visual tone.

---

## 2. Elements

- Game logo and key art
- Primary actions: Play / Character Select, Settings, Credits, Quit
- Version and patch information
- Optional news or announcement panel (fed by launcher or backend)
- Accessibility and language entry points

---

## 3. Design Rules

1. The menu should feel like Elysium, not like a generic default engine title screen.
2. Navigation is simple and keyboard/controller friendly.
3. Load into Character Select is as fast as practical.
4. Art and layout follow [1301-UI-Style.md](../1300-Art/1301-UI-Style.md).
