# 112 — Resource Pack

## Overview
A comprehensive custom resource pack replacing Minecraft's default textures, models, sounds, and UI art with assets matching Elysium's original fantasy art direction ([1300-Art-Style.md](../1300-Art/1300-Art-Style.md)).

## Scope
* **Block & Terrain Retexturing** — used to realize each continent's distinct biomes and architecture ([0101-Continents.md](../0100-World/0101-Continents.md), [0103-Cities.md](../0100-World/0103-Cities.md)).
* **Custom Item Models** — weapons, armor, and accessories ([0500-Weapons.md](../0500-Items/0500-Weapons.md) through [0502-Accessories.md](../0500-Items/0502-Accessories.md)) rendered as bespoke models rather than reskinned vanilla items where feasible.
* **Custom Mob Models** — enemy and NPC models replacing vanilla mob appearances entirely, tied to [0209-NPCs.md](../0200-Lore/0209-NPCs.md) and regional bestiaries.
* **Custom Sound Design** — combat, ambient, and UI sound effects supporting the combat-identity goals in [0401-Combat.md](../0400-Gameplay/0401-Combat.md).
* **Custom UI Art** — icons, frames, and menu backgrounds matching [1303-Fonts.md](../1300-Art/1303-Fonts.md) and [1302-Colour-Palette.md](../1300-Art/1302-Colour-Palette.md).

## Delivery
Installed and kept up to date automatically via the launcher ([1100-Launcher.md](1100-Launcher.md)), versioned alongside client mods ([1101-Client-Mods.md](1101-Client-Mods.md)).
