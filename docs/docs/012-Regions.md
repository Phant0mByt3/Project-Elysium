# 12 — Regions

Regions are the primary zone unit players experience — smaller than a continent, larger than a single city. Each region is scoped to a level band before any building begins, per [002-Core-Pillars.md](002-Core-Pillars.md).

## Region Template

Every region should be documented with:
* **Continent & Level Range**
* **Theme / Biome**
* **Dominant Faction / Race Presence**
* **Key Locations** (cities, dungeons, landmarks)
* **Local Conflict** — the small-scale story driving quests in this region
* **Notable Enemies**
