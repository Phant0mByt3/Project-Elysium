# 42 — Skills

## Overview
Skills are the active and passive abilities a class uses in combat, unlocked progressively while leveling ([046-Leveling.md](046-Leveling.md)) rather than all at once.

## Skill Categories

**Core Skills** — the handful of abilities every player of a class uses regardless of specialization (e.g. a Warrior's basic weapon strikes).

**Specialization Skills** — unlocked at level 10 alongside spec choice ([041-Specializations.md](041-Specializations.md)), define the spec's unique playstyle.

**Utility Skills** — non-damage abilities (movement, crowd control, buffs) available to all specs of a class.

**Ultimate Skills** — a single high-impact, long-cooldown ability unlocked at max level per specialization.

## Skill Anatomy
Every skill should be documented with: name, resource cost, cooldown, range, and a one-sentence description of its mechanical and visual identity. Cooldowns and resource costs must respect the stat formulas in [045-Stats.md](045-Stats.md).

## Unlock Pacing
Skills should unlock roughly every 1–3 levels early on, tapering off after specialization is chosen so that talent point choices ([043-Talent-Trees.md](043-Talent-Trees.md)) become the primary source of build variety at higher levels — supporting Pillar 3 in [002-Core-Pillars.md](002-Core-Pillars.md).

Full per-class skill lists are populated during Phase 2 gameplay systems development ([003-Roadmap.md](003-Roadmap.md)).
