## 1. Overview

Developer Guidelines are the practical “how we work” companion to formal standards: communication, ownership, definition of done, and expected professionalism.

---

## 2. Expectations

- Document as you build  
- Prefer small, reviewable changes  
- Leave code and systems better than you found them  
- Escalate risk early  
- Respect the vision and pillars when making trade-offs
