# Game Mechanics

> The systems that define how players interact with Elysium.

---

# Core Philosophy

Elysium is designed as an MMORPG experience.

Minecraft mechanics are not the primary gameplay system.

Combat, movement, abilities, inventory, progression, and interaction are redesigned to create a fantasy RPG experience.

Every mechanic should support:

* Player immersion
* Class identity
* Skill expression
* Exploration
* Progression
* Cooperation

---

# Combat System

Combat is designed around active abilities rather than vanilla Minecraft attacks.

Players use:

* Basic attacks
* Class abilities
* Special skills
* Ultimate abilities
* Defensive abilities
* Movement abilities

Combat should reward timing, positioning, and understanding of enemy behaviour.

---

# Ultimate System

Ultimate abilities are powerful skills requiring energy before use.

Energy is generated through combat actions.

Example:

```
Attack enemies
      |
      v
Generate Energy
      |
      v
Energy reaches maximum
      |
      v
Ultimate becomes available
      |
      v
Press 1 or 2
      |
      v
Powerful ability activated
```

Ultimate abilities are designed to create memorable combat moments.

---

# Class Movement Abilities

The Alt key provides a unique movement ability based on the player's class.

The ability is not a simple sprint.

It represents the identity of the class.

Examples:

## Warrior

Charge forward with increased movement speed.

## Mage

Arcane teleportation over a short distance.

## Rogue

Shadow dash.

## Druid

Nature-enhanced speed movement.

## Paladin

Divine movement ability.

## Hunter

Quick evasive movement.

# User Interface

Elysium uses a custom MMORPG-style interface.

The interface displays:

* Health
* Mana
* Energy
* Skills
* Cooldowns
* Buffs
* Debuffs
* Quest information
* Party information
* Target information

The UI replaces Minecraft's default HUD.

---

# Key Rebinding

All controls can be changed through the settings menu.

Players can configure:

* Abilities
* Menus
* Movement actions
* Interface shortcuts
* Combat controls

The default layout is designed for accessibility, but players are free to customize their experience.

---

# Future Controls

Possible future support:

* Controller input

* Advanced UI customization

# Design Goal

The player should never feel like they are playing Minecraft.

The goal is for movement, combat, abilities, and interfaces to feel natural for a fantasy MMORPG.

The engine is Minecraft.

The experience is Elysium.
