# 53 — Loot

## Overview
General loot design principles governing how items drop, are distributed, and feel to receive. See [054-Loot-Tables.md](054-Loot-Tables.md) for the specific per-encounter tables built on top of these principles.

## Rarity Tiers
* **Common (White)** — vendor trash, sold for Aurum.
* **Uncommon (Green)** — basic questing/leveling gear.
* **Rare (Blue)** — dungeon-quality gear, meaningful upgrades.
* **Epic (Purple)** — raid-quality gear and top-tier crafted items.
* **Legendary (Orange)** — unique, named items with distinct effects; see [055-Legendary-Items.md](055-Legendary-Items.md).
* **Relic (Gold)** — the rarest tier, tied directly to Age of Concord artifacts; see [056-Relics.md](056-Relics.md).

## Distribution Rules
* Group loot uses a need/greed/pass roll system for group-eligible drops, with personal loot as the default for solo-lootable trash and quest rewards.
* Loot should be visible and celebratory — a rare-or-higher drop should always have a distinct visual/audio cue.
* Bosses should never feel like a "loot pinata" — see [054-Loot-Tables.md](054-Loot-Tables.md) for drop rate philosophy.

## Player Fantasy
Receiving loot should feel like a story beat, not just a numbers update — item flavor text (see [143-Quest-Writing-Guide.md](143-Quest-Writing-Guide.md) tone standards) should tie meaningfully into the lore of where it dropped.
