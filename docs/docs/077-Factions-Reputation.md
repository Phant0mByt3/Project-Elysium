# 77 — Factions Reputation

## Overview
This document covers reputation specifically with the two player factions, the Dawnbound Concord and the Duskward Pact ([33-Factions.md](33-Factions.md)), building on the general system described in [76-Reputation.md](76-Reputation.md).

## Faction Standing
Every character begins Friendly with their chosen faction and Neutral (capped, cannot be raised without a faction-change) with the opposing faction, reflecting the game's PvP-relevant faction divide ([84-PvP.md](84-PvP.md), [86-Territory-Control.md](86-Territory-Control.md)).

## Rewards by Tier
* **Honored** — access to faction-exclusive daily quest hubs ([72-Daily-Quests.md](72-Daily-Quests.md)).
* **Revered** — faction-exclusive mount ([91-Mounts.md](91-Mounts.md)) and cosmetic set ([93-Cosmetics.md](93-Cosmetics.md)).
* **Exalted** — faction-exclusive title ([75-Titles.md](75-Titles.md)) and a unique faction-flavored weapon transmog appearance.

## Faction Changes
A rare, costly service allowing a player to switch factions, resetting faction reputation appropriately. Not intended as a casual choice — framed narratively as a significant character decision, tying back into the main story's themes of ideological division ([30-Lore.md](30-Lore.md)).

## Design Rules
Faction reputation rewards should never create a raw power gap between Concord- and Pact-aligned players in PvP — cosmetic and convenience rewards only, keeping [49-Balance.md](49-Balance.md)'s cross-faction parity intact.
