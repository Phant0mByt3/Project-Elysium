# 77 — Factions Reputation

## Overview
This document covers reputation specifically with the two player factions, the Dawnbound Concord and the Duskward Pact ([033-Factions.md](033-Factions.md)), building on the general system described in [076-Reputation.md](076-Reputation.md).

## Faction Standing
Every character begins Friendly with their chosen faction and Neutral (capped, cannot be raised without a faction-change) with the opposing faction, reflecting the game's PvP-relevant faction divide ([084-PvP.md](084-PvP.md), [086-Territory-Control.md](086-Territory-Control.md)).

## Rewards by Tier
* **Honored** — access to faction-exclusive daily quest hubs ([072-Daily-Quests.md](072-Daily-Quests.md)).
* **Revered** — faction-exclusive mount ([091-Mounts.md](091-Mounts.md)) and cosmetic set ([093-Cosmetics.md](093-Cosmetics.md)).
* **Exalted** — faction-exclusive title ([075-Titles.md](075-Titles.md)) and a unique faction-flavored weapon transmog appearance.

## Faction Changes
A rare, costly service allowing a player to switch factions, resetting faction reputation appropriately. Not intended as a casual choice — framed narratively as a significant character decision, tying back into the main story's themes of ideological division ([030-Lore.md](030-Lore.md)).

## Design Rules
Faction reputation rewards should never create a raw power gap between Concord- and Pact-aligned players in PvP — cosmetic and convenience rewards only, keeping [049-Balance.md](049-Balance.md)'s cross-faction parity intact.
