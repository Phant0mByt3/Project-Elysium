# Simulated Civilisation

## Purpose

This document defines the systems used to make the world of Elysium feel alive beyond player interaction.

A simulated civilisation means that the world continues operating even when players are not present.

Cities grow, factions make decisions, NPCs follow routines, economies change, and events happen naturally based on the state of the world.

The goal is to create a world that feels like a living fantasy civilisation rather than a collection of gameplay locations.

---

# Core Philosophy

Players should feel like they entered an existing world.

The world should not exist only for the player.

NPCs should have:

* Jobs
* Homes
* Relationships
* Daily routines
* Personal goals
* Faction loyalty
* Histories

A city should feel like a place where people live, not a menu with buildings around it.

# Long-Term Goal

The civilisation system should make players believe:

> "The world would continue even if I never logged in."

The greatest achievement is when players create memories because the world feels like a real place.

Elysium is not just a game world.

It is a simulated civilisation.
