# 01 — Vision

## The Core Promise

*"Every journey begins with a single step. Every legend begins with a single player."*

Project Elysium exists to make players forget they are standing on Minecraft blocks. Within ten minutes of character creation, a new player should feel like they have opened a fantasy novel, not loaded a mod pack.

## The Experience We're Building

A player logging into Elysium for the first time should feel:

1. **Immersion** — a custom UI, custom sounds, a custom resource pack, and a world with no floating dirt blocks or vanilla mob spawns to break the illusion.
2. **Purpose** — every quest they take has a reason to exist, tied to the main story, a region's local conflict, or a character's arc.
3. **Progression** — meaningful choices at every level-up, not just bigger numbers.
4. **Belonging** — a faction, a guild, and a server community they want to return to.

## Long-Term Vision

Elysium is designed to be played for years, not weeks. The initial release covers two continents, one main story arc, and a handful of dungeons and one raid tier — but the architecture (see [120-Plugin-Architecture.md](120-Plugin-Architecture.md)) is built from day one to support the full roadmap in [003-Roadmap.md](003-Roadmap.md): more continents, deeper class trees, seasonal content, and multi-year expansions in the style of [150-Expansion-01.md](150-Expansion-01.md) and beyond.

## Guiding Question

Every design decision on this project is filtered through one question:

> "Does this make the player believe in Elysium a little more, or a little less?"

If a feature — however cool — breaks immersion, undermines progression, or feels like busywork, it does not ship. See [002-Core-Pillars.md](002-Core-Pillars.md) for the concrete principles derived from this vision.
