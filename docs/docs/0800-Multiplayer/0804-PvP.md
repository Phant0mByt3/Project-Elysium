## 1. Overview

PvP (player versus player) content spans structured Arenas ([0805-Arenas.md](0805-Arenas.md)), open-world contested zones ([0816-World-PvP.md](0816-World-PvP.md)), and large-scale Territory Control ([0806-Territory-Control.md](0806-Territory-Control.md)), all built around the Dawnbound Concord versus Duskward Pact faction divide established in [0203-Factions.md](../0200-Lore/0203-Factions.md).

## 2. PvP Flagging

Players in neutral zones must voluntarily flag for PvP before engaging opposing-faction players, while designated contested zones (primarily in Vethmoor's border regions) apply automatic flagging, giving players clear control over their exposure to open-world PvP.

## 3. Combat Balance in PvP

Certain values (crowd control duration, burst damage caps) are adjusted separately for PvP contexts to keep player-vs-player fights fair without weakening PvE boss design — see [0401-Combat.md](../0400-Gameplay/0401-Combat.md), Section 6.

## 4. PvP Progression

Dedicated PvP currency and reputation tracks reward consistent PvP participation with PvP-specific gear and cosmetics, kept intentionally separate from PvE progression so neither system feels mandatory for the other.

## 5. PvP Content Types

| Type | Scale | Structure |
| --- | --- | --- |
| Arenas | 2v2, 3v3 | Instanced, ranked |
| World PvP | Open-ended | Unstructured, zone-based |
| Territory Control | Large group | Structured objective-based |

## 6. Design Philosophy

PvP is designed to be a genuine alternative endgame path, not an afterthought bolted onto PvE systems — see [0817-Competitive-Systems.md](0817-Competitive-Systems.md) for the broader competitive framework this fits into.

## 7. Fairness and Balance Review

PvP balance is reviewed on the same cadence as PvE combat balance ([0309-Balance.md](../0300-Characters/0309-Balance.md)), with dedicated PvP tuning passes to address issues that only manifest in player-versus-player contexts.
