# 94 — Emotes

## Overview
Emotes are player-triggered animations and (where applicable) sound effects used for social expression and roleplay, reinforcing the game's identity as a persistent social world (Pillar 4, [02-Core-Pillars.md](02-Core-Pillars.md)).

## Categories
* **Basic Emotes** — available to all characters from the start (wave, sit, dance, bow, laugh).
* **Racial Emotes** — unique to each playable race ([34-Races.md](34-Races.md)), reinforcing racial identity and culture.
* **Unlockable Emotes** — earned through achievements ([74-Achievements.md](74-Achievements.md)), seasonal events ([87-Seasons.md](87-Seasons.md)), or rare drops.

## Design Rules
* Emotes should never be usable in a way that disrupts combat or grants any gameplay advantage.
* Racial emotes should be written and animated with input from the lore team to stay consistent with each race's culture as described in [34-Races.md](34-Races.md).

## Technical Notes
Emote definitions (animation, sound, chat bubble text) are a client-mod responsibility — see [111-Client-Mods.md](111-Client-Mods.md).
