# 125 — API

## Overview
Internal and (eventually) external-facing APIs supporting tools like combat logging, guild websites, and companion apps — a Phase 2+ concern, but scoped early to avoid painful retrofits.

## Internal APIs
* **Combat Logging** — structured combat event export, feeding balance analysis ([49-Balance.md](49-Balance.md)) and potential player-facing damage meters.
* **Economy Data** — Auction House price history ([103-Auction-House.md](103-Auction-House.md)) for internal economy health monitoring.
* **Guild Data** — roster, progression, and bank summaries for potential guild-management tooling.

## External-Facing (Future)
A read-only public API exposing character profiles, guild rosters, and achievement data — useful for community sites and guild-recruitment tools, similar to genre conventions. Scoped as a post-launch feature, not required for Phase 6 ([03-Roadmap.md](03-Roadmap.md)).

## Design Principles
* All API access is authenticated and rate-limited, coordinated with [124-Authentication.md](124-Authentication.md) and [126-Security.md](126-Security.md).
* API schemas should be versioned from day one to avoid breaking third-party or internal tooling on future updates.
