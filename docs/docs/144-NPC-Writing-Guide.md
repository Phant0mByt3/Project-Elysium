# 144 — NPC Writing Guide

## Overview
Standards for writing consistent, memorable NPC dialogue and characterization, extending the quest writing guide ([143-Quest-Writing-Guide.md](143-Quest-Writing-Guide.md)) to cover characters as a category unto themselves.

## Every NPC Needs
* A name, home location, and role, tracked in [039-NPCs.md](039-NPCs.md).
* A one-sentence "voice" description (e.g. "gruff but secretly sentimental," "formal to the point of coldness") that any writer can pick up and stay consistent with.
* At least one line of ambient/idle dialogue beyond their quest text, for immersion (Pillar in [002-Core-Pillars.md](002-Core-Pillars.md)).

## Race & Culture Consistency
NPC dialogue should reflect their race and culture as established in [034-Races.md](034-Races.md) — a dwarven blacksmith and a high-elf scholar should never sound interchangeable.

## Faction Consistency
Dawnbound-aligned NPCs should reflect Concord values (order, cooperative rebuilding); Duskward-aligned NPCs should reflect Pact values (self-reliance, skepticism of the old order) — see [033-Factions.md](033-Factions.md). Avoid making one faction cartoonishly "evil"; both should read as sincere, defensible worldviews per the evenhanded framing in [030-Lore.md](030-Lore.md).

## Reuse
Before creating a new NPC, check [039-NPCs.md](039-NPCs.md) — an existing character may fit the narrative need better than a new one.
