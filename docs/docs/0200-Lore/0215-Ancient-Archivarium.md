The Hall of Forgotten Futures

**Unused ideas.**

Things that were planned but never happened.

**The Infinite Library**

The main area.

Thousands of floating books, glowing records, portals to different archives.

**One important rule I would add:**

* The Archivarium should never answer every mystery.

* Some books should be incomplete.

* Some records should be damaged.

* Some portals should remain locked.

The moment players know everything, the magic disappears.

---

The Archivarium should feel like the place where Elysium stores its secrets, not where it gives them all away.
