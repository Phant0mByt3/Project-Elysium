# 50 — Weapons

## Weapon Types
* **One-Handed Swords / Axes / Maces** — usable by most melee classes, often paired with a shield or off-hand.
* **Two-Handed Swords / Axes / Maces / Polearms** — higher base damage, primarily Warrior/Paladin.
* **Daggers** — Rogue-primary, enable specific finesse-based abilities.
* **Bows / Crossbows** — Ranger-primary ranged weapons.
* **Staves / Wands** — Mage, Necromancer, Cleric, Druid primary caster weapons.
* **Shields** — off-hand, tank-focused, contributes heavily to Armor ([45-Stats.md](45-Stats.md)).

## Design Rules
* Weapon type restricts which classes can equip it, but not which specialization — a Vanguard and Berserker Warrior use the same weapon pool.
* Weapon damage and stat budget scale with item level per the loot table framework in [54-Loot-Tables.md](54-Loot-Tables.md).
* Visually, weapons should escalate in silhouette and effect flourish as item level increases, giving players a readable sense of gear progression at a glance — see [130-Art-Style.md](130-Art-Style.md).

## Acquisition
Weapons drop from quests, dungeons, raids, and vendors, and can be player-crafted via Blacksmithing ([66-Blacksmithing.md](66-Blacksmithing.md)). Legendary-tier weapons are tracked separately in [55-Legendary-Items.md](55-Legendary-Items.md).

## Enchanting
Weapons can be enhanced with enchantments — see [59-Enchanting.md](59-Enchanting.md) for the full system.
