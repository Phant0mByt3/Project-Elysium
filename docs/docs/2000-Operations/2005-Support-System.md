## 1. Overview

The support system handles individual player issues — account recovery, billing questions, technical problems, and appeals — as distinct from broad community management ([2004-Community-Management.md](2004-Community-Management.md)) and moderation enforcement ([2003-Moderation.md](2003-Moderation.md)).

## 2. Support Categories

* **Account Issues** — recovery, security, compromised accounts ([1204-Authentication.md](../1200-Technical/1204-Authentication.md)).
* **Technical Issues** — client crashes, connection problems, launcher issues ([1100-Launcher.md](../1100-Client/1100-Launcher.md)).
* **Gameplay Issues** — stuck quests, lost items, transaction errors.
* **Moderation Appeals** — routed to the appeals process in [2003-Moderation.md](2003-Moderation.md).

## 3. Ticket Pipeline

Player-submitted tickets are triaged by category and severity, with automated self-service options (FAQ, common fix guides) offered first for common issues, reserving human support time for genuinely novel or complex problems.

## 4. Response Time Targets

| Category | Target First Response |
| --- | --- |
| Account Security | Fastest tier — treated as urgent |
| Billing | Priority |
| Gameplay/Technical | Standard |
| General Inquiry | Standard |

## 5. GM Intervention Tools

For issues requiring direct intervention (a lost item due to a bug, a stuck quest state), support staff use the admin tools described in [2008-Staff-Tools.md](2008-Staff-Tools.md), with every intervention logged for accountability, consistent with the audit trail requirements in [1214-Admin-Tools.md](../1200-Technical/1214-Admin-Tools.md).

## 6. Self-Service Resources

A searchable knowledge base covering common issues and fixes reduces ticket volume for straightforward problems, freeing human support capacity for issues that genuinely require it.

## 7. Feedback Loop to Development

Recurring support issues are flagged back to the development team as a signal of underlying bugs or unclear UX, feeding into both [2014-Bug-Reports.md](2014-Bug-Reports.md) and the broader feedback pipeline in [2013-Player-Feedback.md](2013-Player-Feedback.md).
