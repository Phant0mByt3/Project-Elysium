# 51 — Armour

## Armor Categories
* **Cloth** — lowest base armor, highest Intellect budget; Mage, Necromancer, Cleric.
* **Leather** — moderate armor and Agility budget; Rogue, Ranger, Druid.
* **Mail** — higher armor, balanced budget; Ranger (secondary), Druid (secondary).
* **Plate** — highest armor, Strength/Stamina focused; Warrior, Paladin.

## Slots
Head, Shoulders, Chest, Hands, Waist, Legs, Feet, Cloak, plus two Accessory slots covered in [52-Accessories.md](52-Accessories.md).

## Set Bonuses
Armor from the same dungeon or raid tier shares a themed visual set. Equipping multiple pieces from the same set grants a bonus effect (2-piece and 4-piece thresholds), reinforcing the value of running content repeatedly rather than mixing loot at random — see [54-Loot-Tables.md](54-Loot-Tables.md) for how sets are distributed.

## Progression
Armor item level scales through: quest rewards (early leveling) → dungeon drops (mid-level) → crafted gear ([58-Crafting.md](58-Crafting.md), tailoring/blacksmithing) → raid drops (endgame). This mirrors the leveling curve in [46-Leveling.md](46-Leveling.md).

## Visual Standards
Each armor class (Cloth/Leather/Mail/Plate) should be silhouette-distinct even at a distance, so a player's role is readable in group content without opening a character sheet — see [130-Art-Style.md](130-Art-Style.md).
