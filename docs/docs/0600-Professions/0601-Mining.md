# 0601 — Mining

## Overview
Mining is a gathering profession focused on extracting ore and stone from mineral veins found throughout the open world, particularly dense in Vethmoor's mountainous regions ([0102-Regions.md](../0100-World/0102-Regions.md)).

## Core Loop
Locate a mineral vein → mine it with an equipped pickaxe → receive raw ore, occasional gems (feeding Jewelcrafting, [0608-Jewelcrafting.md](0608-Jewelcrafting.md)) → smelt ore into bars for use in Blacksmithing ([0606-Blacksmithing.md](0606-Blacksmithing.md)).

## Regional Distribution
Lower-tier ore veins are common across Aurelia's hills; higher-tier ore becomes prevalent in Vethmoor's Ember Deeps and Ironpeak Holds regions, tying the profession's progression to the same regional level curve used elsewhere ([0102-Regions.md](../0100-World/0102-Regions.md)).

## Design Notes
* Vein respawn timers should be tuned to avoid both server-wide scarcity and complete depletion of any single node farm.
* Rare ore types should occasionally spawn from world events or be gated behind specific regions to keep exploration valuable for gatherers.
