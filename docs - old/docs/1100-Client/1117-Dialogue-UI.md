## 1. Overview

The Dialogue UI presents NPC conversations, quest text, and player response options in a structured, readable format that matches the MMORPG fantasy rather than vanilla Minecraft chat interaction.

---

## 2. Layout Elements

- NPC name, title, and optional portrait or model
- Main dialogue body
- List of player response options
- Quest accept / decline / complete controls when relevant
- Reputation or faction indicators where useful

---

## 3. Design Rules

1. Text is comfortable to read at the supported UI scales.
2. Response options are clearly distinguishable and keyboard/mouse accessible.
3. The UI can display longer lore passages without feeling cramped.
4. Visual treatment follows the diegetic, handcrafted style of [1301-UI-Style.md](../1300-Art/1301-UI-Style.md).
