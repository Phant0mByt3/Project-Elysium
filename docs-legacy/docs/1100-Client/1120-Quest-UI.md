## 1. Overview

The Quest UI comprises the quest log, on-screen tracker, and related notification elements that keep the player informed about active and available objectives.

---

## 2. Components

- Full quest log with categories (Main, Side, Daily, World, Completed)
- Compact tracker panel with objective progress
- Accept / decline / complete panels integrated with dialogue
- Optional chapter or campaign framing for the Main Quest

---

## 3. Design Rules

1. Active objectives are always findable without digging through menus.
2. Main Quest progress is visually distinct from optional content.
3. The tracker can be customised or minimised without losing critical information.
4. Text length and formatting follow the writing standards so that the UI does not overflow or truncate important details.
